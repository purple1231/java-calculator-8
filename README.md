# java-calculator-precourse

# 기능 요구사항

* 쉼표(`,`) 또는 콜론(`:`)을 구분자로 가지는 문자열을 입력받아 각 숫자의 합을 반환한다.
* 구분자 외에 다른 문자가 포함될 경우 예외를 발생시킨다.
* 사용자가 직접 커스텀 구분자를 지정할 수 있다.
* 커스텀 구분자는 `//`와 `\n` 사이의 문자를 사용한다. (예: `//;\n1;2;3`)
* 입력받은 숫자 중에 음수가 포함되어 있으면 `RuntimeException`을 발생시킨다.
* 입력값이 null이거나 빈 문자열일 경우 0을 반환한다.



# 요구 기능 정리

계산기 핵심 로직 구현
* 전달된 문자열이 null 이거나 빈 문자열인지 검증하고, 해당하면 0을 반환한다.

구분자 처리 기능
* 기본 구분자(`,` 와 `:`)를 사용하여 문자열을 분리한다.
* `//`와 `\n` 사이에 커스텀 구분자가 있는지 확인하고, 있다면 해당 구분자를 기준으로 문자열을 분리한다.

숫자 변환 및 검증
* 분리된 각 문자열 조각을 숫자로 변환한다.
* 변환 과정에서 숫자가 아닌 값이 포함되어 있으면 `RuntimeException`을 발생시킨다.
* 변환된 숫자가 음수일 경우 `RuntimeException`을 발생시킨다.

최종 결과 반환
* 모든 유효한 숫자의 합을 구하여 반환한다.

입출력 처리
* 사용자로부터 계산할 문자열을 입력받는다.
* 계산 결과를 화면에 출력한다.
